12Routing & NAT

Relevanz ★★★Routing-Tabelle ausfüllen = KlassikerLernzeit ca. 100 min
AUF EINEN BLICK
  • Routing-Tabelle: Zielnetz · Maske/Präfix · Next Hop (Gateway) · Interface.
  • Direkt angeschlossene Netze brauchen keinen Next Hop. Für alles Unbekannte gilt die Default-Route 0.0.0.0/0.
  • Bei mehreren passenden Einträgen gewinnt der spezifischste (längstes Präfix, „Longest Prefix Match“).
  • NAT/PAT übersetzt private in öffentliche Adressen; Port-Forwarding (DNAT) macht interne Server von außen erreichbar.

Routing-Tabelle

SpalteBedeutung
Zielnetz (Netz-ID)Netz, das erreicht werden soll
Maske / PräfixGröße des Zielnetzes
Next Hop / GatewayIP-Adresse des nächsten Routers – liegt immer im selben Netz wie eine eigene Schnittstelle
Interfaceeigene Schnittstelle, über die das Paket den Router verlässt (eth0, g0/1, tun0)
MetrikKosten des Weges; kleiner = besser
TYPISCHE PRÜFUNGSAUFGABE: ROUTING-TABELLE ERSTELLEN
  LAN A 192.168.1.0/24                     LAN B 192.168.2.0/24
        │ .1                                     │ .1
     [eth0]                                   [eth0]
   Router R1 [eth1] .1 ── 10.0.0.0/30 ── .2 [eth1] Router R2 [eth2] .1 ── 203.0.113.0/30
── .2 Provider → Internet

Erstellen Sie die Routing-Tabelle von R1.

ZielnetzPräfixNext HopInterfaceErklärung
192.168.1.0/24– (direkt)eth0eigenes LAN
10.0.0.0/30– (direkt)eth1Transfernetz
192.168.2.0/2410.0.0.2eth1LAN B über R2
0.0.0.0/010.0.0.2eth1Default-Route: alles andere (Internet) über R2

Die Route zu 192.168.2.0/24 könnte hier auch entfallen, weil die Default-Route ebenfalls zu R2 führt. In Prüfungen trotzdem angeben, wenn „alle Netze“ verlangt sind. R2 braucht umgekehrt eine Route zu 192.168.1.0/24 über 10.0.0.1 – sonst kommt keine Antwort zurück!

Longest Prefix Match: Ziel 10.1.5.9, Einträge 10.0.0.0/8 und 10.1.0.0/16 → der /16-Eintrag gewinnt, weil er genauer ist.

First Hop Redundancy (HSRP, VRRP): Zwei Router teilen sich eine virtuelle Gateway-IP (und MAC). Fällt der aktive Router aus, übernimmt der Standby-Router in Sekunden; die Clients behalten ihr Default-Gateway und merken nichts. HSRP ist Cisco-proprietär, VRRP ein offener Standard.

NAT und PAT

  • NAT (Network Address Translation): Der Router ersetzt die private Quelladresse durch eine öffentliche.
  • PAT / NAT-Overload / Masquerading: Viele interne Geräte teilen sich eine öffentliche IP; unterschieden wird über den Quellport. Standard in jedem Firmen- und Heimrouter.
  • Port-Forwarding (Destination NAT): Anfragen an öffentliche IP:Port werden an einen internen Server weitergeleitet (z. B. 203.0.113.1:443 → 172.16.1.10:443 in der DMZ).
  • Nachteile von NAT: Ende-zu-Ende-Adressierung geht verloren, Probleme mit manchen Protokollen (IPsec-AH, SIP). Bei IPv6 ist NAT nicht nötig; Schutz übernimmt die Firewall.

traceroute/tracert nutzt das TTL-Feld: Jeder Router senkt TTL um 1; bei 0 schickt er eine ICMP-„Time Exceeded“-Meldung zurück. So wird jeder Hop sichtbar. Sternchen (*) = keine Antwort (Firewall oder Routingproblem an dieser Stelle).

BEGRIFFSFAMILIEN – aus den IHK-Prüfungen (Zahl = so oft bisher gefragt)
ProtokolleDistance-Vector = z. B. RIP: kennt nur Nachbarn, Metrik = Hops, langsame Konvergenz 1× · Link-State = z. B. OSPF: kennt die ganze Topologie, schnelle Konvergenz 1× · Metrik = Kosten eines Weges, kleiner = besser 1× · Administrative Distanz = Vertrauenswert der Quelle, wenn mehrere Protokolle denselben Weg kennen
