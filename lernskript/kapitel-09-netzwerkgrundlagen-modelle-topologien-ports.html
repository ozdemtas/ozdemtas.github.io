9Netzwerkgrundlagen: Modelle, Topologien & Ports

Relevanz ★★Grundlage für alle weiteren KapitelLernzeit ca. 75 min
AUF EINEN BLICK
  • OSI-Modell mit 7 Schichten; Merksatz von unten: „Please Do Not Throw Sausage Pizza Away“.
  • Switch = Schicht 2 (MAC-Adressen), Router = Schicht 3 (IP-Adressen), Firewall mit Port-Regeln = Schicht 4, NGFW/Proxy = bis Schicht 7.
  • TCP = verbindungsorientiert, zuverlässig (3-Wege-Handshake). UDP = verbindungslos, schnell (VoIP, DNS, DHCP, Streaming).
  • Topologie im LAN: Stern/Baum; Verkabelung: Primär (Gelände, LWL) · Sekundär (Gebäude) · Tertiär (Etage, Kupfer max. 100 m).
  • Wichtigste Ports auswendig: 22 SSH · 25 SMTP · 53 DNS · 67/68 DHCP · 80 HTTP · 443 HTTPS · 587 Submission · 993 IMAPS · 3389 RDP (Liste → Anhang A).

Kapselung: Beim Senden gibt jede Schicht ihren Header dazu (Daten → Segment → Paket → Frame → Bits), beim Empfänger wird in umgekehrter Reihenfolge entpackt. Eine MAC-Adresse hat 48 Bit (z. B. 00:1A:2B:3C:4D:5E ); die ersten 24 Bit (OUI) kennzeichnen den Hersteller.

3-Wege-Handshake (TCP): Client → SYN → Server · Server → SYN-ACK → Client · Client → ACK → Server. Danach fließen Daten. Abbau mit FIN / ACK .

Ports adressieren die Anwendung auf dem Host: 0–1023 Well-known Ports (Serverdienste) · 1024–49151 Registered Ports · 49152–65535 dynamische Ports (Quellports der Clients). IP-Adresse + Port + Protokoll = Socket (z. B. 192.0.2.10:443/TCP).

FALLE

DNS nutzt UDP 53 für normale Anfragen, aber TCP 53 für Zonentransfers und große Antworten. In Firewall-Regeln daher oft beides freigeben.

Strukturierte Verkabelung (EN 50173) teilt die Gebäudeverkabelung in drei Bereiche:

  • Primärbereich (Campus/Gelände): zwischen Gebäuden, meist Singlemode-LWL.
  • Sekundärbereich (Gebäude/Steigbereich): zwischen Gebäude- und Etagenverteiler, meist Multimode-LWL.
  • Tertiärbereich (Etage/horizontal): vom Etagenverteiler zur Anschlussdose, Kupfer (Cat 6A/Cat 7), max. 90 m fest verlegt + Patchkabel = 100 m.

Prüfverfahren gegen Übertragungsfehler: Ein Paritätsbit ergänzt die Daten so, dass die Anzahl der Einsen gerade (even) bzw. ungerade (odd) ist. Beispiel gerade Parität: 1011001 hat 4 Einsen → Paritätsbit 0. Erkennt einzelne Bitfehler, korrigiert sie aber nicht. Ethernet nutzt eine Prüfsumme (CRC/FCS) am Frame-Ende.

Bridge: verbindet zwei Netzsegmente auf Schicht 2 und leitet anhand der MAC-Adressen weiter; ein Switch ist im Prinzip eine Bridge mit vielen Ports. CIFS ist der alte Name von SMB (Windows-Dateifreigaben).

Ü9.2 Sprache ist zeitkritisch. Ein verspätet nachgesendetes Paket nützt nichts mehr, TCP-Wiederholungen würden nur Verzögerung und Jitter erzeugen. UDP hat weniger Overhead und geringere Latenz; kleine Verluste sind hörbar tolerierbar.

Ü9.3 Primär (zwischen Gebäuden, 400 m): Singlemode-LWL (Multimode wäre bei 10 Gbit/s und mehr grenzwertig). Sekundär (Gebäudeverteiler → Etagenverteiler): Multimode-LWL. Tertiär (Etagenverteiler → Arbeitsplatz): Kupfer Cat 6A, max. 90 m + Patchkabel. Topologie: erweiterter Stern/Baum (Core → Gebäude → Etage → Endgerät), für Ausfallsicherheit redundante Uplinks zwischen den Gebäuden.
