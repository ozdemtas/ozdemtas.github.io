DDie 30 häufigsten Fallen

Lies diese Liste am Abend vor der Prüfung. Jede Zeile hat schon Punkte gekostet.

#FalleRichtig
1Schleife bis <= Length< Length ; Index beginnt bei 0
2max = 0max = array[0]
3Summe/Zähler nicht initialisiertvor der Schleife auf 0 setzen
4Ganzzahldivision beim Mittelwertin double umwandeln, Division durch 0 abfangen
5Aggregat in WHEREHAVING
6Spalte im SELECT fehlt im GROUP BYalle nicht aggregierten Spalten gruppieren
7= NULLIS NULL
8UPDATE/DELETE ohne WHEREimmer WHERE setzen
9Hosts ohne −22h − 2; Gateway zählt als Host
10Subnetze nicht der Größe nach vergeben (VLSM)größtes zuerst
11IPv6 :: zweimalnur einmal pro Adresse
12Bit und Byte vermischt× 8; Datenraten in Bit, Speicher in Byte
13MiB und MB vermischtbinär 1.024, dezimal 1.000
14W statt kW bei Stromkosten÷ 1.000
15Hot-Spare mitgerechnetvorher abziehen
16RAID als Backup bezeichnetRAID = Verfügbarkeit, kein Backup
17Snapshot als Backupgleicher Storage, kein Backup
18differenziell ↔ inkrementell verwechseltDifferenziell = seit der Vollsicherung
19RPO ↔ RTO verwechseltRPO = Datenverlust (Point), RTO = Ausfallzeit (Time)
20deny-Regel vor allow-RegelReihenfolge: speziell vor allgemein, deny any am Ende
21Quell- statt Zielport in Firewall-RegelDienstport = Zielport
22DNS-Freigabe vergessenUDP/TCP 53
23Rückroute vergessenbeide Router brauchen Routen
24Port in mehreren VLANs untaggednur ein untagged VLAN pro Port
25MX zeigt auf IPMX → Hostname → A/AAAA
26Verschlüsseln mit eigenem privaten Schlüsselmit öffentlichem Schlüssel des Empfängers; privat = signieren
27Zutritt/Zugang/Zugriff verwechseltRaum / System / Daten
28Pseudonymisierte Daten als „nicht personenbezogen“nur Anonymisierung hebt den Personenbezug auf
29Versteckte SSID als Sicherheitsmaßnahmekeine; WPA3/802.1X nutzen
30Mehr Antworten als verlangtgenau so viele nennen wie gefordert
